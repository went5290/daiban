# 本地提醒助手

一个简单的 Windows 桌面提醒工具：输入某天某个时间要做的事情，到时间后弹出提醒窗口。

现在包含启动封面、应用图标和更精致的桌面界面。

## 使用方法

1. 推荐双击 `start_reminder_silent.vbs`，它会申请管理员权限并在后台启动，不显示命令行窗口。
2. 如果静默启动失败，可以双击 `start_reminder.bat` 查看命令行日志。
3. 在“时间”里填写提醒时间，格式为 `YYYY-MM-DD HH:MM`，例如 `2026-06-06 09:30`。
4. 在“事项”里写要提醒的内容。
5. 点击“添加提醒”。

程序运行时会每 5 秒检查一次提醒。点击窗口右上角关闭按钮后，程序会最小化到后台继续运行；只有点击“退出程序”才会真正停止提醒。

## 数据保存

提醒事项会自动保存在同目录下的 `reminders.json` 文件中。下次启动程序会自动读取。

## 注意

如果双击无法启动，请先确认电脑已经安装 Python，并且命令行可以运行：

```powershell
python --version
```

如果程序仍然闪退，请查看同目录下是否生成了 `error.log`。把其中内容发给我，就能继续定位具体原因。

`start_reminder.bat` 会自动申请管理员权限。如果 Windows 弹出确认框，请点击“是”。

## 打包成 exe

双击 `build_exe.bat` 可以生成正式的 Windows 可执行文件。生成后在 `dist` 文件夹里会看到：

```text
DaibanReminder.exe
```

这个 exe 使用无命令行窗口模式运行。
